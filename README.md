# AllTracks Mobile 🏁

Мобильное приложение для платформы AllTracks - трекер экстремальных видов спорта.

## 📱 Функциональность

### Аутентификация
- ✅ Регистрация нового пользователя
- ✅ Вход в систему
- ✅ Сохранение токена авторизации
- ✅ Выход из аккаунта

### Треки
- ✅ Просмотр списка треков
- ✅ Фильтрация по видам спорта
- ✅ Детальная информация о треке
- ✅ Карта с местоположением
- ✅ Галерея изображений
- ✅ Рейтинг и сложность

### Пользователи
- ✅ Профиль пользователя
- ✅ Редактирование информации
- ✅ Статистика аккаунта

### Соревнования
- ✅ Просмотр соревнований
- ✅ Предстоящие события
- ✅ Активные соревнования

## 🚀 Установка

### Предварительные требования
- Node.js 18+
- npm или yarn
- Expo CLI
- Android Studio (для Android)
- Xcode (для iOS)

### Установка зависимостей
```bash
cd alltracks-mobile
npm install
```

### Запуск приложения
```bash
# Для разработки
npm start

# Для Android
npm run android

# Для iOS
npm run ios

# Для веб
npm run web
```

## 🏗️ Архитектура

### Структура проекта
```
src/
├── components/     # Переиспользуемые компоненты
├── navigation/     # Навигация приложения
├── screens/        # Экраны приложения
├── services/       # API сервисы
├── types/          # TypeScript типы
└── utils/          # Утилиты
```

### Основные компоненты
- **AppNavigator** - Главный навигатор приложения
- **HomeScreen** - Главный экран со списком треков
- **TrackDetailScreen** - Детальный экран трека
- **ProfileScreen** - Экран профиля пользователя
- **LoginScreen** - Экран входа
- **RegisterScreen** - Экран регистрации

### API интеграция
- **apiService** - Сервис для работы с backend API
- **Автоматическая авторизация** - Добавление токена к запросам
- **Обработка ошибок** - Перехват и обработка ошибок API

## 🔧 Конфигурация

### Backend URL
По умолчанию приложение подключается к:
```
http://89.125.123.92:8081/api/v1.0
```

Для изменения URL отредактируйте файл `src/services/api.ts`.

### Переменные окружения
Приложение использует Expo, поэтому переменные окружения можно настроить через `app.json` или `eas.json`.
